# fleet-office

A tiny static status page: a three-floor office tower where each bot sits at its own desk.
Generated by `build_site.py` from a private status file; contains no personal details
(emails, phones, addresses, codes and people's names are stripped, sensitive topics are hidden).

The page asks search engines not to index it (`noindex,nofollow` meta tag and `robots.txt`), but a public
GitHub Pages site is still reachable by anyone who has the link.
